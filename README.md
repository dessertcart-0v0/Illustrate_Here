# Illustrate Here — 이 메시지 그리기

[마리나라] 원하는 턴에 일러스트레이터 에이전트를 불러오는 확장 프로그램

## 무엇을 하나

Marinara Engine의 AI 메시지 동작 줄에 그림 아이콘을 하나 더해요.
누르면 그 메시지 시점의 장면을 엔진의 **일러스트레이터(Illustrator) 에이전트**가 그려요.
채팅마다 저절로 돌 때와 같은 지시문 · 같은 모델 설정으로 돌고, 확장은 "언제 돌릴지"만 정해요.

## 설치

1. 엔진 쪽 준비 (처음 한 번만)
   - 서버 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 서버를 다시 켜요.
   - Settings → Advanced → Danger Zone에서 **Allow third-party extension imports**를 켜요.
   - 에이전트 받기에서 **Illustrator**를 설치해요.
   - 이미지 생성 연결을 지정해요. Illustrator 에이전트에 지정하거나, Settings → 연결 → 기본값 → 이미지에 지정하면 돼요.
2. Settings → Addons → External Extensions에서 **`illustrate_here.extension.json`**을 가져와요.
3. 검토 화면에서 **Full page access**를 확인하고 승인해요.
4. 페이지를 새로고침해요.

> `illustrate_here.js`를 그대로 가져오면 엔진이 샌드박스 확장으로 등록해서 아이콘이 뜨지 않아요.
> 꼭 `.extension.json`으로 가져오세요. 이미 `.js`로 가져왔다면 확장 편집 화면에서 Full page access를 켜고 다시 승인하면 돼요.

## 쓰는 법

- AI 메시지에 마우스를 올리면(폰은 메시지를 누르면) 아래에 동작 줄이 떠요.
  **휴지통 바로 왼쪽**의 그림 아이콘을 눌러요.
- 도는 동안 아이콘이 빙글 돌아요. 그때 다시 누르면 취소돼요.
- 다 그리면 그림이 그 메시지 아래와 갤러리에 붙어요.
- 그릴지 말지는 에이전트가 정해요. 안 그리기로 하면 화면 아래에 에이전트가 댄 이유가 떠요.
- 한 번에 한 메시지만 그려요.

## 알아 둘 점

- **Illustrator를 채팅에 켜 둘 필요는 없어요.** 켜 두면 엔진이 정해진 메시지 간격마다 저절로 그리니, 누를 때만 그리려면 빼 두세요.
- **채팅 설정을 잠깐 바꿔요.** 엔진은 채팅의 에이전트 목록에 있는 에이전트만 수동으로 돌려 줘요. 그래서 누르는 순간 Illustrator를 그 채팅에 넣었다가, 실행이 시작되면 바로 빼요.
  - 이미 Illustrator를 켜 둔 채팅은 건드리지 않아요.
  - 되돌릴 때는 이 확장이 넣은 것만 빼요. 그사이 바꾼 다른 에이전트 설정은 그대로예요.
  - 도중에 페이지가 닫히면 다음에 확장이 켜질 때 되돌려요. 되돌리지 못하면 화면에 알려 줘요. 그때는 채팅 설정의 에이전트에서 Illustrator를 꺼 주세요.
  - 넣고 빼는 사이(보통 1초 안쪽)에 그 채팅에서 메시지를 보내면, 그 턴에 Illustrator가 같이 돌 수 있어요.
- 엔진의 갤러리 그리기 버튼과 `/illustrate` 명령은 에이전트가 아니라 별도의 그림 설명 작성기로 마지막 메시지만 그려요. 이 확장은 에이전트 자체를, 고른 메시지에서 돌려요.
- 에이전트가 배경도 바꾸기로 하면(채팅의 자동 배경이 켜져 있을 때) 배경도 자동 실행 때처럼 바뀌어요.
- 그리기 전 프롬프트 검토 창은 뜨지 않아요.
- 취소는 그 채팅에서 돌고 있는 에이전트 실행을 멈춰요. 답변을 생성하는 중에 누르면 그 생성도 멈출 수 있어요.
- 동작 줄은 마우스를 올린 동안만 보여서, 도는 표시도 그 메시지에 마우스를 올려야 보여요.
- 롤플레이 · 대화 모드의 AI 메시지에만 떠요. 유저 메시지, 편집 중인 메시지, 게임(GM) 모드에는 뜨지 않아요.

## 안 될 때

화면 아래 안내에 엔진이 알려 준 이유가 그대로 나와요.

| 안내 | 원인 |
|---|---|
| `Agent returned invalid JSON instead of the requested image_prompt format` | 에이전트의 모델이 형식에 안 맞는 답을 냈어요(거절, 빈 답 등). |
| `No image generation connection is set …` | 이미지 생성 연결이 없어요. |
| `No runnable agents were found …` | Illustrator 에이전트가 엔진에 설치되어 있지 않아요. |
| 아이콘이 안 보이고 콘솔에 `document is not defined` | `.js`로 가져와 샌드박스로 등록됐어요. 위 설치 안내를 보세요. |
